# PusiServer

> **Pusi-os** · Ваш личный сервер экосистемы Pusi: агентский стек,
> хранение и доступ к информации на своих устройствах через интернет.
> Вшит в [PusiDesk](https://github.com/pusi-os/PusiDesk) и умеет жить
> standalone — на домашнем компьютере или на вашем VPS.

## Посыл

Свой сервер — это «облако», которое вы можете открыть и погладить.
PusiServer отдаёт экосистеме три вещи, которые обычно продают за
подписку в чужом облаке:

1. **Агентский бэкенд**: голосовой и текстовый интерфейс к моделям,
   работа по расписанию и по событиям, по вашим правилам;
2. **Хранение**: память компаньона, заметки, файлы сквада, резервные
   копии — на вашем диске;
3. **Удалённый доступ**: ваши устройства добираются до этой информации
   откуда угодно через интернет — но только ваши и только по правилам,
   которые вы установили.

## Манифест Pusi (коротко)

1. **Своё — по умолчанию.** Всё, что хранится, хранится у вас.
2. **Приватность — архитектура.** Телеметрии нет; ключи живут в вашем
   конфиге; доступ — только для ваших устройств.
3. **Мозги на выбор.** Локальные модели (llama.cpp, Ollama) или любой
   OpenAI-совместимый облачный провайдер — без вшитых имён.
4. **Код открыт.** GPL-3.0: можно читать и проверять, чем именно
   занимается ваш сервер.

## Что умеет

- **Агентский стек ASR-LLM-TTS**: распознавание → модель → речь. Голос
  и текст через WebSocket и HTTP; сервер ведёт диалоги компаньона и
  агентские сессии. Локальный инференс — llama.cpp/Ollama, облако —
  любой OpenAI-совместимый; смена — одна строка конфига.
- **Память и файлы**: хранилище в Markdown/JSON, Obsidian-совместимое,
  с корзиной вместо молчаливых удалений.
- **Доступ ваших устройств через интернет**: телефон с Pots, десктоп
  с PusiDesk и прошивка PotSquad добираются к хранилищу и компаньону
  извне — по вашим токенам устройств.
- **OTA для прошивок**: веб-страница сервера раздаёт подписанные сборки
  прошивки PotSquad — устройства сквада обновляются с откатом при сбое;
  автообновление можно выключить полностью.
- **MCP-инструменты**: внешние навыки компаньона подключаются по
  протоколу MCP — от домашних сервисов в локальной сети до корпоративных
  API, которые вы сами решите отдать агенту.
- **Расписания и проактивность**: always-on поведение, как у облачных
  агентов, только на расписаниях вашего сервера: разбудить компаньона,
  проверить почту, собрать утренний обзор — по вашим правилам.

## Два способа жизни

| | Внутри PusiDesk | Standalone (этот репо) |
|---|---|---|
| Где | ваш десктоп, запускается вместе с ним | домашний мини-ПК / VPS 24/7 |
| Как запустить | кнопка «включить сервер» в приложении | `python3 -m pusi_server.main` / docker-compose |
| Кому нужен | тем, у кого десктоп обычно включён | тем, кто хочет, чтобы агент отвечал всегда, когда выключено всё остальное |
| Данные | тот же диск | отдельное хранилище, легко переносится между машинами |

## Сравнение с облаками

| | Облако (Dots / Muse) | PusiServer |
|---|---|---|
| Где агент спит и работает | чужой дата-центр | ваш сервер |
| Кто читает ваши письма | провайдер, если вы их подключили | никто, кроме вас |
| Сколько стоит | $0–100 в месяц | цена VPS, который вы и так платите |
| Какой провайдер | вшитый | любой OpenAI-совместимый, на ваш выбор |
| Что при взломе аккаунта | доступ к их копии всего | доступ к вашему серверу — который вы сами настраивали и знаете |

## Экосистема Pusi-os

- [`PotSquad`](https://github.com/pusi-os/PotSquad) — прошивка
  устройства-компаньона: экран, динамик, микрофон, аккумулятор,
  детектор слежки, меш-чат сквада, голосовой агент.
- [`Pots`](https://github.com/pusi-os/Pots) — нативное Android-приложение,
  бэкенд экосистемы всегда с вами.
- [`PusiDesk`](https://github.com/pusi-os/PusiDesk) — нативный десктоп
  Linux / Windows / macOS со встроенной версией этого сервера.
- [`PusiServer`](https://github.com/pusi-os/PusiServer) — этот репозиторий.

## Запуск

```sh
# домашний сервер
pip install -r requirements.txt
python3 -m pusi_server.main --host 0.0.0.0 --port 8000

# VPS — то же самое плюс HTTPS от вашего реверс-прокси
# конфиг — config.toml; секреты — в окружении, не в репозитории
```

Подробности — `docs/ru/SETUP.md`: реверс-прокси, токены устройств,
хранение, бэкапы, OTA прошивок, подключения MCP.

## Безопасность по умолчанию

- Доступ к хранилищу и компаньону — по токенам устройств, которые вы
  выдаёте вручную.
- Никаких открытых «для всех» портов: доступ ограничен вашими правилами.
- Секреты — только в переменных окружения и локальных конфигах; в
  репозитории их никогда нет.
- Резервные копии — обычные файлы на вашем диске: копируйте и шифруйте
  как хотите — обязательного облачного бэкапа у нас нет.

## Статус

Активная разработка: агентский стек, хранение и OTA работают; сейчас
дозревают MCP-инструменты и синхронизация хранилищ между серверами
и устройствами.
